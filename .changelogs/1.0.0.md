First release. GTBlocker keeps chosen items uncraftable in GregTech: New Horizons until an admin unlocks them, ideally at an unlock party.

### What it blocks
- Every crafting grid: vanilla, GregTech and modded tables alike, since it gates the recipe match itself.
- GregTech machines: recipe lookup, processing and the Assembly Line.
- AE2 autocrafting: locked items can't be planned or assembled, and terminals don't offer them as craftable.

### Unlock parties
- Schedule a reveal for a time (`21:30`, `+45m`), or start one live with a 10 second countdown.
- Chat reminders, a HUD countdown, a big UNLOCKED title, fanfare and fireworks, optionally at a party spot.
- A shoutout for the first player to craft each unlocked item.
- With gtnh-voice installed, an "Unlock Party" voice group opens before the reveal.
- Admins can also unlock items quietly, without a party.

### Admin GUI
`/gtblocker`, or a keybind (unbound by default). Lock items by dragging them in from NEI, plan parties, read the unlock history and manage admins. Everyone can open it; non-admins get a read-only view.

### Setup
- Install the same version on the server and on every client. Both need **Java 25** (GTNH 2.9 with lwjgl3ify); built and tested against GTNH 2.9.0-RC-2.
- GTNHLib and ModularUI2 are required. GregTech, AE2, NEI and gtnh-voice are optional.
- Admins are GTBlocker's own list; OP doesn't matter. Add the first one from the server console with `gtblocker admin add <player>`. After that, admins manage the list themselves.
- English and Italian translations.

Fixes a dedicated-server crash. Update the server and every client together: everyone needs the same version to join.

### Fixed
- Scheduling an unlock party crashed dedicated servers with `NoSuchMethodError: EnumChatFormatting.func_110646_a`. The party message was cleaned with a method that only exists on the client. From the GUI this took the whole server down; `/gtblocker party now` and `party at` failed with "An unknown error occurred". Singleplayer was not affected.
- An admin action that fails on the server is now logged instead of crashing the server.

### Build
- The build now fails when server code uses client-only Minecraft or mod code, the kind of mistake behind this crash.
